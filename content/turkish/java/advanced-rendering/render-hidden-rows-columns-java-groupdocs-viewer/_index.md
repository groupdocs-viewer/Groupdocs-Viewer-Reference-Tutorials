## Gizli verilerle Excel'i HTML'ye nasıl dönüştürülür

Excel çalışma kitabını HTML'ye dönüştürürken gizli satır ve sütunların görünür olmasını sağlamak için, dosyayı GroupDocs.Viewer ile yükler, gizli öğeleri render etmek için `SpreadsheetOptions` yapılandırır, istenen çıktı formatı için `HtmlViewOptions` ayarlar ve ardından HTML dosyalarını oluşturmak için görüntüleyiciyi (viewer) çağırırsınız. Aşağıdaki adımları izleyerek bunu gerçekleştirebilirsiniz.

### Adım 1: Çıktı dizini yolunu tanımlayın
Oluşturulan HTML dosyalarının kaydedileceği klasörü belirtin:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Adım 2: HTML görünüm seçeneklerini yapılandırın
`HtmlViewOptions`, HTML dosyalarının nasıl üretileceğini kontrol eder; kaynakların gömülü mü yoksa ayrı dosyalar olarak mı kaydedileceği dahil.  
`HtmlViewOptions` sınıfı, GroupDocs.Viewer'da HTML render'ı için merkezi yapılandırma nesnesidir.

### Adım 3: Gizli sütun ve satırların render edilmesini etkinleştirin
`SpreadsheetOptions`, dönüşüm sırasında gizli satır ve sütunların görünürlüğünü açıp kapamanıza olanak tanır.  
`SpreadsheetOptions`, gizli hücreler, ızgara çizgileri ve çalışma sayfası seçimi gibi elektronik tabloya özgü özelliklerin nasıl ele alınacağını belirleyen ayar kapsayıcısıdır.

### Adım 4: Viewer'ı belgeyle başlatın ve render edin
`Viewer` sınıfı, GroupDocs.Viewer'da belgeleri render etmek için kullanılan temel bileşendir.  
Bir `Viewer` örneği oluşturun, Excel dosya yolunu geçirin ve hazırlanmış seçeneklerle `view` metodunu çağırın.  
`Viewer` sınıfı, GroupDocs.Viewer'ın giriş noktasıdır; kaynak belgeyi okur ve istenen çıktı formatını üretir.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Sıkça Sorulan Sorular

**S: `setRenderHiddenColumns(true)` etkinleştirmek performansı etkiler mi?**  
C: Gizli sütunları render etmek küçük bir ek yük ekler, ancak tipik çalışma kitapları için etkisi minimaldir. Çok büyük sayfalar için bellek kullanımını izleyin ve JVM yığın boyutunu artırmayı düşünün.

**S: XLSX dosyasını birden çok sayfa yerine tek bir HTML sayfasına dönüştürebilir miyim?**  
C: Evet, `{0}` yer tutucusu olmadan `HtmlViewOptions` içinde özel bir dosya adı ayarlayarak tüm çalışma sayfalarını içeren tek bir HTML dosyası oluşturabilirsiniz.

**S: Gizli elektronik tablo verilerini sadece belirli çalışma sayfaları için nasıl gösteririm?**  
C: Gizli render'ı etkinleştirmeden önce `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` kullanarak belirli sayfaları hedefleyin.

**S: Dönüştürmeden sonra araç çubuğunu veya navigasyonu gizlemenin bir yolu var mı?**  
C: GroupDocs.Viewer tarafından oluşturulan HTML çıktısı statiktir; oluşturulan şablonu düzenleyerek veya özel CSS uygulayarak navigasyon öğelerini manuel olarak kaldırabilirsiniz.

**S: Gizli satır/sütun render'ı için hangi GroupDocs.Viewer sürümü gereklidir?**  
C: Özellik **22.0** sürümünden itibaren mevcuttur; en iyi performans ve destek için en son kararlı sürümü (şu anda 25.2) kullanmanızı öneririz.
