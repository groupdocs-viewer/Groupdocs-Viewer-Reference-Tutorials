# Convert Excel to HTML and render hidden rows & columns in Java spreadsheets using GroupDocs.Viewer

Are you struggling to **convert Excel to HTML** and visualize hidden rows and columns within a spreadsheet when converting it to HTML using Java? You're not alone! Many developers face this challenge while trying to maintain the integrity of data visualization across different formats. This tutorial will guide you through how to effectively render hidden rows and columns in spreadsheets using GroupDocs.Viewer for Java, ensuring no crucial information is lost during conversion.

## What is “convert Excel to HTML”?

Converting Excel to HTML transforms an `.xlsx` workbook into web‑ready HTML pages while preserving the original layout, cell styles, formulas, and data. The resulting HTML can be displayed in any modern browser without needing Microsoft Office installed, making it ideal for web portals, reporting dashboards, and collaborative platforms.

## Why render hidden spreadsheet data?

Rendering hidden rows and columns ensures that every piece of information stored in the workbook becomes visible in the HTML output, which is crucial for auditability, data analysis, and educational scenarios. By exposing hidden cells, you avoid accidental data loss and guarantee that downstream consumers see the full dataset exactly as it exists in the source file.

## How to convert Excel to HTML with hidden data

To convert an Excel workbook to HTML while ensuring hidden rows and columns become visible, you load the file with GroupDocs.Viewer, configure the `SpreadsheetOptions` to render hidden elements, set up `HtmlViewOptions` for the desired output format, and then invoke the viewer to generate the HTML files. Follow the steps below to accomplish this.

### Step 1: Define output directory path

Specify the folder where the generated HTML files will be saved:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Step 2: Configure HTML view options

`HtmlViewOptions` controls how HTML files are produced, including whether resources are embedded or saved as separate files.  
The `HtmlViewOptions` class is the central configuration object for HTML rendering in GroupDocs.Viewer.

### Step 3: Enable rendering of hidden columns and rows

`SpreadsheetOptions` lets you toggle the visibility of hidden rows and columns during conversion.  
`SpreadsheetOptions` is the settings container that determines how spreadsheet‑specific features—such as hidden cells, grid lines, and worksheet selection—are handled.

### Step 4: Initialize Viewer with document and render

The `Viewer` class is the primary component used to render documents in GroupDocs.Viewer.  
Create a `Viewer` instance, pass the Excel file path, and invoke the `view` method with the prepared options.  
The `Viewer` class is GroupDocs.Viewer’s entry point; it reads the source document and produces the requested output format.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Frequently asked questions

**Q: Does enabling `setRenderHiddenColumns(true)` affect performance?**  
A: Rendering hidden columns adds a small overhead, but the impact is minimal for typical workbooks. For very large sheets, monitor memory usage and consider increasing JVM heap size.

**Q: Can I convert an XLSX file to a single HTML page instead of multiple pages?**  
A: Yes, set a custom file name in `HtmlViewOptions` without the `{0}` placeholder to generate a single HTML file that contains all worksheets.

**Q: How do I display hidden spreadsheet data only for specific worksheets?**  
A: Use `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` to target particular sheets before enabling hidden rendering.

**Q: Is there a way to hide the toolbar or navigation after conversion?**  
A: The HTML output generated by GroupDocs.Viewer is static; you can manually remove navigation elements by editing the generated template or applying custom CSS.

**Q: Which version of GroupDocs.Viewer is required for hidden row/column rendering?**  
A: The feature is available starting from version **22.0**; we recommend using the latest stable release (currently 25.2) for best performance and support.
