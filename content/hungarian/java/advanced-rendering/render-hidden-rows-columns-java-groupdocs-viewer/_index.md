## Hogyan konvertáljunk Excelt HTML-re rejtett adatokkal

Az Excel munkafüzet HTML-re konvertálásához, miközben a rejtett sorok és oszlopok láthatóvá válnak, betöltöd a fájlt a GroupDocs.Viewer-rel, beállítod a `SpreadsheetOptions`-t a rejtett elemek rendereléséhez, konfigurálod a `HtmlViewOptions`-t a kívánt kimeneti formátumhoz, majd meghívod a viewer-t a HTML fájlok generálásához. Kövesd az alábbi lépéseket a megvalósításhoz.

### 1. lépés: Kimeneti könyvtár útvonalának meghatározása
Add meg a mappát, ahová a generált HTML fájlok mentésre kerülnek:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### 2. lépés: HTML nézet beállításainak konfigurálása
`HtmlViewOptions` szabályozza, hogyan készülnek a HTML fájlok, beleértve azt is, hogy az erőforrások beágyazottak vagy külön fájlokként mentettek legyenek.  
A `HtmlViewOptions` osztály a központi konfigurációs objektum a HTML rendereléshez a GroupDocs.Viewer-ben.

### 3. lépés: Rejtett oszlopok és sorok renderelésének engedélyezése
`SpreadsheetOptions` lehetővé teszi a rejtett sorok és oszlopok láthatóságának be- vagy kikapcsolását a konverzió során.  
A `SpreadsheetOptions` a beállítások tárolója, amely meghatározza, hogyan kezelje a táblázatspecifikus funkciókat – például a rejtett cellákat, rácsvonalakat és munkalap kiválasztást.

### 4. lépés: Viewer inicializálása dokumentummal és renderelés
A `Viewer` osztály a fő komponens a dokumentumok rendereléséhez a GroupDocs.Viewer-ben.  
Hozz létre egy `Viewer` példányt, add meg az Excel fájl útvonalát, és hívd meg a `view` metódust a előkészített beállításokkal.  
A `Viewer` osztály a GroupDocs.Viewer belépési pontja; beolvassa a forrásdokumentumot és előállítja a kért kimeneti formátumot.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Gyakran feltett kérdések

**Q: Befolyásolja a teljesítményt a `setRenderHiddenColumns(true)` engedélyezése?**  
A: A rejtett oszlopok renderelése kis extra terhet jelent, de a hatás minimális a tipikus munkafüzeteknél. Nagyon nagy lapok esetén figyeld a memóriahasználatot és fontold meg a JVM heap méretének növelését.

**Q: Átalakíthatom az XLSX fájlt egyetlen HTML oldalra több oldal helyett?**  
A: Igen, állíts be egy egyedi fájlnevet a `HtmlViewOptions`‑ban a `{0}` helyőrző nélkül, hogy egyetlen HTML fájlt generálj, amely az összes munkalapot tartalmazza.

**Q: Hogyan jelenítsem meg a rejtett táblázati adatokat csak bizonyos munkalapokon?**  
A: Használd a `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` metódust, hogy a rejtett renderelés engedélyezése előtt célzott munkalapokat válassz.

**Q: Van mód a eszköztár vagy a navigáció elrejtésére a konverzió után?**  
A: A GroupDocs.Viewer által generált HTML kimenet statikus; manuálisan eltávolíthatod a navigációs elemeket a generált sablon szerkesztésével vagy egyedi CSS alkalmazásával.

**Q: Melyik GroupDocs.Viewer verzió szükséges a rejtett sor/oszlop rendereléséhez?**  
A: A funkció a **22.0** verziótól érhető el; ajánljuk a legújabb stabil kiadás használatát (jelenleg 25.2) a legjobb teljesítmény és támogatás érdekében.
