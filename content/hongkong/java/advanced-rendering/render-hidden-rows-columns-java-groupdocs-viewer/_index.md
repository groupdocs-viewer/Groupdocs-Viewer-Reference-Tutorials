# 轉換 Excel 為 HTML 並在 Java 試算表中渲染隱藏的列與欄位，使用 GroupDocs.Viewer

您是否在使用 Java 將 Excel 轉換為 HTML 時，苦於 **convert Excel to HTML** 且無法顯示試算表中隱藏的列與欄位？您並不孤單！許多開發者在嘗試在不同格式之間保持資料可視化完整性時，都會遇到此挑戰。本教學將指導您如何使用 GroupDocs.Viewer for Java 有效渲染試算表中的隱藏列與欄位，確保轉換過程中不遺失任何關鍵資訊。

- **隱藏的列與欄位會在 HTML 輸出中顯示嗎？** 當您啟用正確的選項時，隱藏的資料會像可見儲存格一樣被渲染。

## 什麼是「convert Excel to HTML」？

將 Excel 轉換為 HTML 會把 `.xlsx` 活頁簿轉換成可在網頁上顯示的 HTML 頁面，同時保留原始的版面配置、儲存格樣式、公式與資料。產生的 HTML 可在任何現代瀏覽器中直接開啟，無需安裝 Microsoft Office，十分適合用於網站入口、報表儀表板與協作平台。

## 為什麼要渲染隱藏的試算表資料？

渲染隱藏的列與欄位可確保活頁簿中所有資訊皆在 HTML 輸出中可見，這對於稽核、資料分析與教學情境尤為重要。透過顯示隱藏儲存格，可避免意外遺失資料，確保下游使用者看到的資料集與來源檔案完全一致。

## 如何在保留隱藏資料的情況下將 Excel 轉換為 HTML

將 Excel 活頁簿轉換為 HTML，並確保隱藏的列與欄位能被顯示的流程如下：使用 GroupDocs.Viewer 載入檔案，設定 `SpreadsheetOptions` 以渲染隱藏元素，配置 `HtmlViewOptions` 取得所需的輸出格式，最後呼叫 Viewer 產生 HTML 檔案。請依照以下步驟執行。

### 步驟 1：定義輸出目錄路徑

指定產生的 HTML 檔案要儲存的資料夾路徑：
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### 步驟 2：設定 HTML 檢視選項

`HtmlViewOptions` 控制 HTML 檔案的產出方式，包括資源是內嵌還是另存為獨立檔案。  
`HtmlViewOptions` 類別是 GroupDocs.Viewer 中負責 HTML 渲染的核心設定物件。

### 步驟 3：啟用隱藏列與欄位的渲染

`SpreadsheetOptions` 讓您在轉換過程中切換隱藏列與欄位的可見性。  
`SpreadsheetOptions` 是設定容器，決定試算表特定功能（如隱藏儲存格、格線、工作表選取）如何處理。

### 步驟 4：以文件初始化 Viewer 並執行渲染

`Viewer` 類別是 GroupDocs.Viewer 用於渲染文件的主要元件。  
建立 `Viewer` 實例，傳入 Excel 檔案路徑，並以先前準備好的選項呼叫 `view` 方法。  
`Viewer` 類別是 GroupDocs.Viewer 的入口點；它會讀取來源文件並產生所請求的輸出格式。
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## 常見問題

**Q: 啟用 `setRenderHiddenColumns(true)` 會影響效能嗎？**  
A: 渲染隱藏欄位會產生少量額外開銷，但對於一般活頁簿影響不大。對於極大型工作表，請留意記憶體使用情況，並考慮增大 JVM 堆積。

**Q: 我可以將 XLSX 檔案轉換為單一 HTML 頁面嗎？**  
A: 可以，於 `HtmlViewOptions` 中設定自訂檔名且不使用 `{0}` 佔位符，即可產生包含所有工作表的單一 HTML 檔案。

**Q: 如何僅對特定工作表顯示隱藏的試算表資料？**  
A: 在啟用隱藏渲染前，使用 `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` 針對特定工作表進行設定。

**Q: 轉換後是否可以隱藏工具列或導覽列？**  
A: GroupDocs.Viewer 產生的 HTML 輸出為靜態檔案；您可以自行編輯產生的模板或套用自訂 CSS 以移除導覽元素。

**Q: 需要哪個版本的 GroupDocs.Viewer 才支援隱藏列/欄位渲染？**  
A: 此功能自 **22.0** 版起即提供；建議使用最新穩定版（目前為 25.2）以獲得最佳效能與支援。
