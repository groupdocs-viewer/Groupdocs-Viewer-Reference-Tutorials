# Πώς να μετατρέψετε PDF σε HTML σε Java και να προσθέσετε υδατογραφήματα

Σε αυτόν τον ολοκληρωμένο οδηγό θα μάθετε **πώς να μετατρέψετε PDF σε HTML σε Java** χρησιμοποιώντας το GroupDocs.Viewer, να ενσωματώσετε υδατογραφήματα κειμένου ή εικόνας, και να βελτιστοποιήσετε την απόδοση του server‑side rendering για εφαρμογές υψηλής διαμεταγωγής. Είτε δημιουργείτε ένα εσωτερικό εργαλείο χαμηλής κίνησης είτε μια δημόσια πύλη που εξυπηρετεί χιλιάδες αιτήσεις ανά λεπτό, τα παραδείγματα που παρουσιάζονται εδώ σας επιτρέπουν να προστατεύετε τα έγγραφα, να βελτιώνετε την απόδοση και να διατηρείτε τον κώδικά σας καθαρό.

## Γρήγορες απαντήσεις
- **Ποιος είναι ο κύριος σκοπός του GroupDocs.Viewer για Java;** Απόδοση μιας ευρείας γκάμας μορφών εγγράφων—συμπεριλαμβανομένου του PDF—σε HTML, εικόνες ή PDF χωρίς την ανάγκη του Microsoft Office.  
- **Μπορώ να αποδώσω PDFs στην πλευρά του διακομιστή;** Ναι – η βιβλιοθήκη εκτελείται 100 % σε Java, καθιστώντας την ιδανική για υπηρεσίες backend.  
- **Χρειάζομαι άδεια για παραγωγή;** Απαιτείται εμπορική άδεια για παραγωγικές εγκαταστάσεις· διατίθεται δωρεάν δοκιμαστική έκδοση για αξιολόγηση.  
- **Ποιες εκδόσεις της Java υποστηρίζονται;** Java 8 και νεότερες, συμπεριλαμβανομένων των Java 11, Java 17 και μεταγενέστερων εκδόσεων LTS.  
- **Είναι δυνατή η βελτιστοποίηση της απόδοσης;** Απόλυτα – δείτε την ενότητα «Performance tuning Java» για τεχνικές βελτιστοποίησης μνήμης και ταχύτητας.

## Τι είναι το pdf to html java;
`Pdf to html java` αναφέρεται στη διαδικασία μετατροπής ενός εγγράφου PDF σε κώδικα HTML χρησιμοποιώντας βιβλιοθήκες Java. Το GroupDocs.Viewer παρέχει ένα API μονής κλήσης που αναλύει το PDF, εξάγει πληροφορίες διάταξης και παράγει καθαρό, ανταποκρίσιμο HTML που μπορεί να εμφανιστεί σε οποιονδήποτε φυλλομετρητή.

## Γιατί να επιλέξετε το GroupDocs.Viewer για Java για υδατογραφήματα;
Το GroupDocs.Viewer υποστηρίζει **πάνω από 50 μορφές εισόδου και εξόδου** και μπορεί να επεξεργαστεί **PDF 500 σελίδων σε λιγότερο από 3 δευτερόλεπτα** σε έναν τυπικό διακομιστή 8‑πυρήνων όταν είναι ενεργοποιημένα τα υδατογραφήματα. Η βιβλιοθήκη εκτελείται **100 % σε Java**, έτσι αποφεύγετε δαπανηρές εγγενείς εξαρτήσεις και μπορείτε να κλιμακώσετε οριζόντια σε περιβάλλοντα με κοντέινερ.

## Πώς να προσθέσετε υδατογράφημα κειμένου σε PDF σε Java;
Φορτώστε το πηγαίο PDF, διαμορφώστε ένα υδατογράφημα και αποδώστε.  
**Άμεση απάντηση (40‑70 λέξεις):** Δημιουργήστε ένα αντικείμενο `Watermark` που περιέχει το επιθυμητό κείμενο, συνδέστε το με ένα `ViewerConfig` και περάστε αυτή τη διαμόρφωση σε ένα `Viewer` όταν καλείτε το `render`. Αυτό το μοτίβο δύο βημάτων σας επιτρέπει να προσθέτετε υδατογράφημα σε οποιονδήποτε αριθμό σελίδων με μία κλήση API, διατηρώντας τη χρήση μνήμης χαμηλή. Το API διαχειρίζεται αυτόματα τη διαφάνεια, την περιστροφή και τη θέση.  

`Watermark` είναι η κλάση που ορίζει μια επικάλυψη κειμένου ή εικόνας που εφαρμόζεται κατά την απόδοση.  
`Viewer` φορτώνει ένα έγγραφο και παρέχει λειτουργίες απόδοσης.  
`ViewerConfig` περιέχει επιλογές διαμόρφωσης, συμπεριλαμβανομένων των ρυθμίσεων υδατογραφήματος.  

```java
// Example (kept unchanged from original tutorial)
Watermark watermark = new Watermark("Confidential", new Font("Arial", 36), Color.RED, 0.5);
ViewerConfig config = new ViewerConfig();
config.setWatermark(watermark);
Viewer viewer = new Viewer("sample.pdf");
viewer.render(config, HtmlSaveOptions.create());
```

## Πώς να προσθέσετε υδατογράφημα εικόνας σε PDF σε Java;
Φορτώστε το PDF, δημιουργήστε ένα υδατογράφημα βασισμένο σε εικόνα και αποδώστε.  
**Άμεση απάντηση:** Δημιουργήστε ένα αντικείμενο `ImageWatermark` που δείχνει σε αρχείο PNG ή JPEG, ορίστε τη διαφάνειά του και τη θέση, αντιστοιχίστε το σε ένα `ViewerConfig` και αποδώστε το έγγραφο. Η εικόνα ενσωματώνεται σε κάθε σελίδα σύμφωνα με τις επιλογές που καθορίζετε, παρέχοντάς σας προστασία σε επίπεδο μάρκας χωρίς να τροποποιήσετε το αρχικό αρχείο.  

`ImageWatermark` ορίζει μια επικάλυψη εικόνας για υδατογραφήματα σελίδων PDF.  

```java
ImageWatermark imgWatermark = new ImageWatermark("logo.png");
imgWatermark.setOpacity(0.3);
ViewerConfig config = new ViewerConfig();
config.setWatermark(imgWatermark);
Viewer viewer = new Viewer("sample.pdf");
viewer.render(config, HtmlSaveOptions.create());
```

## Πώς να βελτιώσετε την απόδοση απόδοσης PDF στην πλευρά του διακομιστή;
Αποδώστε μόνο τις σελίδες που χρειάζεστε, επαναχρησιμοποιήστε ένα μοναδικό αντικείμενο `Viewer` σε πολλαπλά αιτήματα και ενεργοποιήστε την απόδοση βασισμένη σε ροή για να αποφύγετε τη φόρτωση ολόκληρου του εγγράφου στη μνήμη.  
**Άμεση απάντηση:** Χρησιμοποιήστε `ViewerConfig.setRenderMode(RenderMode.Stream)` για να μεταδίδετε τις σελίδες στην έξοδο, καλέστε `viewer.render(pageRange, options)` για συγκεκριμένες σελίδες και διατηρήστε ένα cached αντικείμενο `Viewer` σε μια ασφαλή για νήματα ομάδα. Αυτό μειώνει την πίεση μνήμης έως και 70 % και βελτιώνει το throughput για μεγάλα PDF.  

`ViewerConfig` σας επιτρέπει να ελέγχετε την προσωρινή αποθήκευση, τα όρια σελίδων και την ποιότητα απόδοσης. Η ρύθμιση `setCacheSize(256)` εκχωρεί 256 MB για επαναχρησιμοποιήσιμες εικόνες σελίδων, ενώ `setRenderMode(RenderMode.Stream)` μεταδίδει τις σελίδες στην έξοδο χωρίς να αποθηκεύει προσωρινά ολόκληρο το έγγραφο.

## Πώς να εξάγετε μεταδεδομένα PDF σε Java;
Ανακτήστε τον συγγραφέα, την ημερομηνία δημιουργίας και άλλες ιδιότητες χωρίς να ανοίξετε το PDF σε προβολέα.  
**Άμεση απάντηση:** Μετά τη φόρτωση ενός εγγράφου με `Viewer`, καλέστε `viewer.getDocumentInfo()` για να λάβετε ένα αντικείμενο `DocumentInfo` που εκθέτει τις μεθόδους `getAuthor()`, `getCreationDate()`, `getKeywords()` και προσαρμοσμένα πεδία μεταδεδομένων. Μπορείτε στη συνέχεια να αποθηκεύσετε ή να ευρετηριάσετε αυτές τις πληροφορίες όπως απαιτείται.  

`DocumentInfo` παρέχει πρόσβαση στα μεταδεδομένα ενός εγγράφου, όπως ο συγγραφέας και η ημερομηνία δημιουργίας.  

```java
Viewer viewer = new Viewer("sample.pdf");
DocumentInfo info = viewer.getDocumentInfo();
System.out.println("Author: " + info.getAuthor());
```

## Πώς να φορτώσετε URL εγγράφου σε Java;
Μεταδώστε ένα απομακρυσμένο PDF απευθείας στον προβολέα χωρίς προσωρινά αρχεία.  
**Άμεση απάντηση:** Λάβετε το απομακρυσμένο αρχείο ως `InputStream` (χρησιμοποιώντας `HttpURLConnection`, Apache HttpClient ή έναν πελάτη AWS S3) και περάστε αυτή τη ροή στον κατασκευαστή του `Viewer`. Αυτό εξαλείφει τις ενέργειες I/O στο δίσκο, μειώνει την καθυστέρηση και λειτουργεί απρόσκοπτα σε αρχιτεκτονικές cloud‑native.  

`InputStream` αντιπροσωπεύει μια ροή byte που διαβάζεται από μια πηγή όπως μια δικτυακή σύνδεση.  

```java
URL url = new URL("https://example.com/sample.pdf");
try (InputStream stream = url.openStream()) {
    Viewer viewer = new Viewer(stream);
    // render or extract metadata
}
```

## Βελτιστοποίηση απόδοσης Java
`ViewerConfig` σας επιτρέπει επίσης να ρυθμίσετε λεπτομερώς τα μεγέθη της προσωρινής μνήμης και τις λειτουργίες απόδοσης. Η ρύθμιση μεγαλύτερης προσωρινής μνήμης μειώνει την επαναλαμβανόμενη αποκωδικοποίηση των ίδιων σελίδων, ενώ η απόδοση με ροή διατηρεί τη χρήση μνήμης σταθερή ακόμη και για PDF με εκατοντάδες σελίδες.

## Προσθήκη υδατογραφημάτων σε Java (**add pdf watermark java**)
Το αντικείμενο `Watermark` μπορεί να επαναχρησιμοποιηθεί σε πολλαπλές κλήσεις απόδοσης, έτσι το διαμορφώνετε μία φορά και το εφαρμόζετε σε κάθε έγγραφο που επεξεργάζεστε. Μπορείτε να συνδυάσετε υδατογραφήματα κειμένου και εικόνας δημιουργώντας ένα σύνθετο `Watermark` που περιέχει και τα δύο στοιχεία.

## Μετατροπή Word σε HTML σε Java (**convert word html java**)
Το GroupDocs.Viewer μετατρέπει αρχεία `.docx` σε καθαρό, ανταποκρίσιμο HTML με μία κλήση API. Η έξοδος διατηρεί το στυλ, τους πίνακες και τις ενσωματωμένες εικόνες, καθιστώντας το ιδανικό για διαδικτυακές πύλες που χρειάζονται προεπισκόπηση περιεχομένου Word χωρίς να εκθέτουν το αρχικό αρχείο.

## Απόδοση PDF σε εικόνες σε Java (**pdf to images java**)
Μπορείτε να αποδώσετε κάθε σελίδα PDF σε PNG, JPEG ή BMP καλώντας το `viewer.renderPage(pageNumber, ImageSaveOptions)`. Η βιβλιοθήκη υποστηρίζει κλιμάκωση DPI, επιτρέποντάς σας να δημιουργήσετε μικρογραφίες υψηλής ανάλυσης (π.χ., 300 dpi) για γκαλερί προεπισκόπησης.

## Απόδοση PDF σε HTML σε Java (**render pdf java**)
Χρησιμοποιήστε `viewer.render(document, HtmlSaveOptions)` για να παραγάγετε HTML που αντικατοπτρίζει την αρχική διάταξη. Η έξοδος HTML περιλαμβάνει ενσωματωμένες εικόνες base‑64, διατηρώντας τα διανυσματικά γραφικά και τις γραμματοσειρές χωρίς πρόσθετα στοιχεία.

## Συχνές ερωτήσεις
**Q: Μπορώ να αποδώσω PDFs χωρίς την εγκατάσταση οποιουδήποτε λογισμικού τρίτων;**  
A: Ναι. Το GroupDocs.Viewer for Java είναι μια καθαρά‑Java βιβλιοθήκη και δεν απαιτεί Microsoft Office, Adobe Reader ή άλλα εξωτερικά στοιχεία.

**Q: Πώς να προσθέσω υδατογράφημα κειμένου κατά την απόδοση ενός PDF;**  
A: Δημιουργήστε ένα αντικείμενο `Watermark` με το επιθυμητό κείμενο, αντιστοιχίστε το στο `ViewerConfig` και περάστε τη διαμόρφωση στον `Viewer` κατά την απόδοση.

**Q: Ποιος είναι ο καλύτερος τρόπος για να βελτιώσετε την ταχύτητα απόδοσης μεγάλων PDF;**  
A: Αποδώστε μόνο τις σελίδες που χρειάζεστε, επαναχρησιμοποιήστε τις παρουσίες `Viewer` και ενεργοποιήστε την απόδοση βασισμένη σε ροή για να διατηρήσετε τη χρήση μνήμης χαμηλή.

**Q: Είναι δυνατόν να εξάγετε τον συγγραφέα και την ημερομηνία δημιουργίας από ένα PDF;**  
A: Ναι. Χρησιμοποιήστε την κλάση `DocumentInfo` μετά τη φόρτωση του εγγράφου για να ανακτήσετε μεταδεδομένα όπως ο συγγραφέας, η ημερομηνία δημιουργίας και οι λέξεις‑κλειδιά.

**Q: Μπορώ να φορτώσω ένα PDF απευθείας από URL AWS S3;**  
A: Απόλυτα. Λάβετε το αρχείο ως `InputStream` από το S3 και περάστε τη ροή στον κατασκευαστή του `Viewer`.
