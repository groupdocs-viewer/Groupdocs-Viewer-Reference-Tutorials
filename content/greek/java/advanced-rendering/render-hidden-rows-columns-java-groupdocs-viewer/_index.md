## Τι είναι η “μετατροπή Excel σε HTML”

Η μετατροπή Excel σε HTML μετατρέπει ένα βιβλίο εργασίας `.xlsx` σε ιστοσελίδες HTML έτοιμες για το web, διατηρώντας την αρχική διάταξη, τα στυλ κελιών, τους τύπους και τα δεδομένα. Το παραγόμενο HTML μπορεί να εμφανιστεί σε οποιονδήποτε σύγχρονο περιηγητή χωρίς την ανάγκη εγκατάστασης του Microsoft Office, καθιστώντας το ιδανικό για διαδικτυακές πύλες, πίνακες ελέγχου αναφορών και συνεργατικές πλατφόρμες.

## Γιατί να αποδίδουμε κρυφά δεδομένα λογιστικού φύλλου;

Η απόδοση κρυφών γραμμών και στηλών διασφαλίζει ότι κάθε πληροφορία που αποθηκεύεται στο βιβλίο εργασίας γίνεται ορατή στην έξοδο HTML, κάτι που είναι κρίσιμο για την αξιοπιστία, την ανάλυση δεδομένων και εκπαιδευτικά σενάρια. Εκθέτοντας τα κρυφά κελιά, αποφεύγετε τυχαία απώλεια δεδομένων και εγγυάστε ότι οι τελικοί χρήστες βλέπουν το πλήρες σύνολο δεδομένων ακριβώς όπως υπάρχει στο αρχείο προέλευσης.

## Πώς να μετατρέψετε Excel σε HTML με κρυφά δεδομένα

Για να μετατρέψετε ένα βιβλίο εργασίας Excel σε HTML διασφαλίζοντας ότι οι κρυφές γραμμές και στήλες γίνονται ορατές, φορτώνετε το αρχείο με το GroupDocs.Viewer, διαμορφώνετε το `SpreadsheetOptions` ώστε να αποδίδει κρυφά στοιχεία, ορίζετε το `HtmlViewOptions` για την επιθυμητή μορφή εξόδου και, στη συνέχεια, καλείτε το viewer για να δημιουργήσει τα αρχεία HTML. Ακολουθήστε τα παρακάτω βήματα.

### Βήμα 1: Ορισμός διαδρομής φακέλου εξόδου

Καθορίστε το φάκελο όπου θα αποθηκευτούν τα παραγόμενα αρχεία HTML:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Βήμα 2: Διαμόρφωση επιλογών προβολής HTML

`HtmlViewOptions` ελέγχει πώς παράγονται τα αρχεία HTML, συμπεριλαμβανομένου του αν οι πόροι θα ενσωματωθούν ή θα αποθηκευτούν ως ξεχωριστά αρχεία.  
Η κλάση `HtmlViewOptions` είναι το κεντρικό αντικείμενο διαμόρφωσης για την απόδοση HTML στο GroupDocs.Viewer.

### Βήμα 3: Ενεργοποίηση απόδοσης κρυφών στηλών και γραμμών

`SpreadsheetOptions` σας επιτρέπει να ενεργοποιήσετε ή να απενεργοποιήσετε την ορατότητα των κρυφών γραμμών και στηλών κατά τη μετατροπή.  
Το `SpreadsheetOptions` είναι το κοντέινερ ρυθμίσεων που καθορίζει πώς θα αντιμετωπιστούν οι λειτουργίες του λογιστικού φύλλου — όπως κρυφά κελιά, γραμμές πλέγματος και επιλογή φύλλων εργασίας.

### Βήμα 4: Αρχικοποίηση Viewer με έγγραφο και απόδοση

Η κλάση `Viewer` είναι το κύριο στοιχείο που χρησιμοποιείται για την απόδοση εγγράφων στο GroupDocs.Viewer.  
Δημιουργήστε ένα στιγμιότυπο `Viewer`, περάστε τη διαδρομή του αρχείου Excel και καλέστε τη μέθοδο `view` με τις προετοιμασμένες επιλογές.  
Η κλάση `Viewer` είναι το σημείο εισόδου του GroupDocs.Viewer· διαβάζει το πηγαίο έγγραφο και παράγει τη ζητούμενη μορφή εξόδου.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

**Q: Επηρεάζει η ενεργοποίηση του `setRenderHiddenColumns(true)` την απόδοση;**  
A: Η απόδοση κρυφών στηλών προσθέτει μικρό φορτίο, αλλά η επίδραση είναι ελάχιστη για τυπικά βιβλία εργασίας. Για πολύ μεγάλα φύλλα, παρακολουθήστε τη χρήση μνήμης και εξετάστε την αύξηση του heap της JVM.

**Q: Πώς μπορώ να εμφανίσω κρυφά δεδομένα λογιστικού φύλλου μόνο για συγκεκριμένα φύλλα εργασίας;**
