# Převod Excelu do HTML a vykreslení skrytých řádků a sloupců v tabulkách Java pomocí GroupDocs.Viewer

Tento tutoriál vás provede tím, jak efektivně vykreslit skryté řádky a sloupce v tabulkách pomocí GroupDocs.Viewer pro Java, aby během konverze nebyly ztraceny žádné důležité informace.

## Co je „convert Excel to HTML“?

Převod Excelu do HTML transformuje sešit `.xlsx` na webové HTML stránky, přičemž zachovává původní rozvržení, styly buněk, vzorce a data. Výsledné HTML lze zobrazit v jakémkoli moderním prohlížeči bez nutnosti instalace Microsoft Office, což je ideální pro webové portály, přehledové panely a kolaborativní platformy.

## Proč vykreslovat skrytá data v tabulce?

Vykreslení skrytých řádků a sloupců zajišťuje, že každá informace uložená v sešitu bude viditelná ve výstupu HTML, což je klíčové pro auditovatelnost, analýzu dat a vzdělávací scénáře. Odhalením skrytých buněk se vyhnete neúmyslné ztrátě dat a zajistíte, že koncoví uživatelé uvidí kompletní datovou sadu přesně tak, jak existuje ve zdrojovém souboru.

## Jak převést Excel do HTML se skrytými daty

Aby bylo možné převést Excel sešit do HTML a zároveň zajistit, že skryté řádky a sloupce budou viditelné, načtete soubor pomocí GroupDocs.Viewer, nakonfigurujete `SpreadsheetOptions` pro vykreslení skrytých prvků, nastavíte `HtmlViewOptions` pro požadovaný výstupní formát a poté zavoláte viewer k vygenerování HTML souborů. Postupujte podle níže uvedených kroků.

### Krok 1: Definujte cestu výstupního adresáře
Zadejte složku, kam budou uloženy vygenerované HTML soubory:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Krok 2: Nakonfigurujte HTML view options
`HtmlViewOptions` řídí, jak jsou HTML soubory vytvářeny, včetně toho, zda jsou zdroje vloženy nebo uloženy jako samostatné soubory.  
Třída `HtmlViewOptions` je centrální konfigurační objekt pro HTML vykreslování v GroupDocs.Viewer.

### Krok 3: Povolit vykreslování skrytých sloupců a řádků
`SpreadsheetOptions` vám umožňuje přepínat viditelnost skrytých řádků a sloupců během konverze.  
`SpreadsheetOptions` je kontejner nastavení, který určuje, jak jsou zpracovávány specifické funkce tabulky — jako skryté buňky, mřížky a výběr listů.

### Krok 4: Inicializujte Viewer s dokumentem a vykreslete
Třída `Viewer` je hlavní komponenta používaná k vykreslování dokumentů v GroupDocs.Viewer.  
Vytvořte instanci `Viewer`, předáte cestu k Excel souboru a zavoláte metodu `view` s připravenými možnostmi.  
Třída `Viewer` je vstupní bod GroupDocs.Viewer; načítá zdrojový dokument a vytváří požadovaný výstupní formát.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Často kladené otázky

**Q: Ovlivňuje povolení `setRenderHiddenColumns(true)` výkon?**  
A: Vykreslování skrytých sloupců přidává malé zatížení, ale dopad je minimální pro typické sešity. U velmi velkých listů sledujte využití paměti a zvažte zvýšení velikosti haldy JVM.

**Q: Mohu převést soubor XLSX na jedinou HTML stránku místo více stránek?**  
A: Ano, nastavte vlastní název souboru v `HtmlViewOptions` bez zástupného `{0}`, aby se vygeneroval jeden HTML soubor obsahující všechny listy.

**Q: Jak zobrazit skrytá data tabulky pouze pro konkrétní listy?**  
A: Použijte `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` k cílení na konkrétní listy před povolením vykreslování skrytých buněk.

**Q: Existuje způsob, jak po konverzi skrýt panel nástrojů nebo navigaci?**  
A: HTML výstup generovaný GroupDocs.Viewer je statický; můžete ručně odstranit navigační prvky úpravou vygenerované šablony nebo použitím vlastního CSS.

**Q: Která verze GroupDocs.Viewer je vyžadována pro vykreslování skrytých řádků/sloupců?**  
A: Funkce je k dispozici od verze **22.0**; doporučujeme používat nejnovější stabilní vydání (aktuálně 25.2) pro nejlepší výkon a podporu.
