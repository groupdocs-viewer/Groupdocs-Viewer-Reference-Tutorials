Вы сталкиваетесь с трудностями при **преобразовании Excel в HTML** и визуализации скрытых строк и столбцов в таблице при конвертации её в HTML с помощью Java? Вы не одиноки! Многие разработчики сталкиваются с этой проблемой, пытаясь сохранить целостность визуализации данных в разных форматах. Этот учебник покажет, как эффективно отображать скрытые строки и столбцы в таблицах с использованием GroupDocs.Viewer для Java, гарантируя, что важная информация не будет потеряна при конвертации.

## Быстрые ответы
- **Может ли GroupDocs.Viewer преобразовать Excel в HTML?** Да, он предоставляет готовую поддержку конвертации файлов XLSX в HTML.
- **Будут ли скрытые строки и столбцы видимы в HTML‑выводе?** При включении соответствующих параметров скрытые данные отображаются так же, как и видимые ячейки.

## Что такое «преобразование Excel в HTML»?

Преобразование Excel в HTML превращает рабочую книгу `.xlsx` в готовые к веб‑использованию HTML‑страницы, сохраняя оригинальное расположение, стили ячеек, формулы и данные. Полученный HTML может отображаться в любом современном браузере без необходимости установки Microsoft Office, что делает его идеальным для веб‑порталов, панелей отчетности и совместных платформ.

## Почему отображать скрытые данные таблицы?

Отображение скрытых строк и столбцов гарантирует, что каждая часть информации, хранящаяся в рабочей книге, становится видимой в HTML‑выводе, что критически важно для аудита, анализа данных и образовательных сценариев. Раскрывая скрытые ячейки, вы избегаете случайной потери данных и обеспечиваете, что конечные пользователи видят полный набор данных точно так, как он присутствует в исходном файле.

## Как преобразовать Excel в HTML с отображением скрытых данных

Чтобы преобразовать рабочую книгу Excel в HTML с отображением скрытых строк и столбцов, загрузите файл с помощью GroupDocs.Viewer, настройте `SpreadsheetOptions` для рендеринга скрытых элементов, задайте `HtmlViewOptions` для нужного формата вывода, а затем вызовите viewer для генерации HTML‑файлов. Следуйте шагам ниже, чтобы выполнить это.

### Шаг 1: Определите путь к каталогу вывода
Укажите папку, в которой будут сохранены сгенерированные HTML‑файлы:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Шаг 2: Настройте параметры HTML‑просмотра
`HtmlViewOptions` управляет тем, как создаются HTML‑файлы, включая то, встраиваются ли ресурсы или сохраняются как отдельные файлы.  
Класс `HtmlViewOptions` является центральным объектом конфигурации для HTML‑рендеринга в GroupDocs.Viewer.

### Шаг 3: Включите рендеринг скрытых столбцов и строк
`SpreadsheetOptions` позволяет переключать видимость скрытых строк и столбцов во время конвертации.  
`SpreadsheetOptions` — это контейнер настроек, определяющий, как обрабатываются специфические для таблиц функции, такие как скрытые ячейки, сетка и выбор листов.

### Шаг 4: Инициализируйте Viewer с документом и выполните рендеринг
Класс `Viewer` является основным компонентом, используемым для рендеринга документов в GroupDocs.Viewer.  
Создайте экземпляр `Viewer`, передайте путь к файлу Excel и вызовите метод `view` с подготовленными параметрами.  
Класс `Viewer` — точка входа GroupDocs.Viewer; он читает исходный документ и создает запрошенный формат вывода.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Часто задаваемые вопросы

**Q: Влияет ли включение `setRenderHiddenColumns(true)` на производительность?**  
A: Рендеринг скрытых столбцов добавляет небольшие накладные расходы, но влияние минимально для типичных рабочих книг. Для очень больших листов следите за использованием памяти и рассматривайте возможность увеличения размера кучи JVM.

**Q: Могу ли я преобразовать файл XLSX в одну HTML‑страницу вместо нескольких?**  
A: Да, задайте пользовательское имя файла в `HtmlViewOptions` без плейсхолдера `{0}`, чтобы сгенерировать один HTML‑файл, содержащий все листы.

**Q: Как отобразить скрытые данные таблицы только для определённых листов?**  
A: Используйте `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)`, чтобы выбрать конкретные листы перед включением рендеринга скрытого содержимого.

**Q: Можно ли скрыть панель инструментов или навигацию после конвертации?**  
A: HTML‑вывод, генерируемый GroupDocs.Viewer, статичен; вы можете вручную удалить элементы навигации, отредактировав сгенерированный шаблон или применив пользовательский CSS.

**Q: Какая версия GroupDocs.Viewer требуется для рендеринга скрытых строк/столбцов?**  
A: Функция доступна, начиная с версии **22.0**; мы рекомендуем использовать последнюю стабильную версию (в данный момент 25.2) для лучшей производительности и поддержки.
