# تحويل Excel إلى HTML وعرض الصفوف والأعمدة المخفية في جداول بيانات Java باستخدام GroupDocs.Viewer

هل تواجه صعوبة في **convert Excel to HTML** وتصور الصفوف والأعمدة المخفية داخل جدول البيانات عند تحويله إلى HTML باستخدام Java؟ لست وحدك! يواجه العديد من المطورين هذا التحدي أثناء محاولة الحفاظ على سلامة تصور البيانات عبر صيغ مختلفة. سيوجهك هذا الدرس خطوة بخطوة حول كيفية عرض الصفوف والأعمدة المخفية بفعالية في جداول البيانات باستخدام GroupDocs.Viewer لـ Java، مما يضمن عدم فقدان أي معلومات حيوية أثناء التحويل.

## ما هو “convert Excel to HTML”؟
تحويل Excel إلى HTML يحول مصنف `.xlsx` إلى صفحات HTML جاهزة للويب مع الحفاظ على التخطيط الأصلي، أنماط الخلايا، الصيغ، والبيانات. يمكن عرض HTML الناتج في أي متصفح حديث دون الحاجة إلى تثبيت Microsoft Office، مما يجعله مثاليًا للبوابات الإلكترونية، لوحات تقارير، ومنصات التعاون.

## لماذا عرض بيانات جدول البيانات المخفية؟
يضمن عرض الصفوف والأعمدة المخفية أن كل قطعة من المعلومات المخزنة في المصنف تصبح مرئية في مخرجات HTML، وهو أمر حاسم للمراجعة، تحليل البيانات، والسيناريوهات التعليمية. من خلال كشف الخلايا المخفية، تتجنب فقدان البيانات عن طريق الخطأ وتضمن أن المستهلكين النهائيين يرون مجموعة البيانات الكاملة كما هي في الملف الأصلي.

## كيفية تحويل Excel إلى HTML مع البيانات المخفية

لتحويل مصنف Excel إلى HTML مع ضمان ظهور الصفوف والأعمدة المخفية، تقوم بتحميل الملف باستخدام GroupDocs.Viewer، وتكوين `SpreadsheetOptions` لعرض العناصر المخفية، وإعداد `HtmlViewOptions` للصيغة المطلوبة، ثم تستدعي الـ viewer لتوليد ملفات HTML. اتبع الخطوات أدناه لتحقيق ذلك.

### الخطوة 1: تحديد مسار دليل الإخراج
حدد المجلد الذي سيتم حفظ ملفات HTML المولدة فيه:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### الخطوة 2: تكوين خيارات عرض HTML
`HtmlViewOptions` يتحكم في كيفية إنتاج ملفات HTML، بما في ذلك ما إذا كانت الموارد مدمجة أو محفوظة كملفات منفصلة.  
فئة `HtmlViewOptions` هي كائن التكوين المركزي لعرض HTML في GroupDocs.Viewer.

### الخطوة 3: تمكين عرض الأعمدة والصفوف المخفية
`SpreadsheetOptions` يتيح لك تبديل رؤية الصفوف والأعمدة المخفية أثناء التحويل.  
`SpreadsheetOptions` هو حاوية الإعدادات التي تحدد كيفية معالجة الميزات الخاصة بجداول البيانات—مثل الخلايا المخفية، خطوط الشبكة، واختيار ورقة العمل.

### الخطوة 4: تهيئة Viewer بالمستند وعرضه
فئة `Viewer` هي المكوّن الأساسي المستخدم لعرض المستندات في GroupDocs.Viewer.  
أنشئ مثيلًا من `Viewer`، مرّر مسار ملف Excel، واستدعِ طريقة `view` مع الخيارات المُعدّة.  
فئة `Viewer` هي نقطة الدخول في GroupDocs.Viewer؛ فهي تقرأ المستند المصدر وتنتج الصيغة المطلوبة.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```
