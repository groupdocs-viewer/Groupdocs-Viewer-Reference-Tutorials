## Wie man Excel in HTML mit ausgeblendeten Daten konvertiert
Um eine Excel‑Arbeitsmappe in HTML zu konvertieren und dabei sicherzustellen, dass ausgeblendete Zeilen und Spalten sichtbar werden, laden Sie die Datei mit GroupDocs.Viewer, konfigurieren die `SpreadsheetOptions` zum Rendern ausgeblendeter Elemente, richten `HtmlViewOptions` für das gewünschte Ausgabeformat ein und rufen anschließend den Viewer auf, um die HTML‑Dateien zu erzeugen. Befolgen Sie die nachstehenden Schritte, um dies zu erreichen.

### Schritt 1: Ausgabeverzeichnis festlegen
Geben Sie den Ordner an, in dem die erzeugten HTML‑Dateien gespeichert werden sollen:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Schritt 2: HTML‑Ansichtsoptionen konfigurieren
`HtmlViewOptions` steuert, wie HTML‑Dateien erzeugt werden, einschließlich der Frage, ob Ressourcen eingebettet oder als separate Dateien gespeichert werden.  
Die Klasse `HtmlViewOptions` ist das zentrale Konfigurationsobjekt für das HTML‑Rendering in GroupDocs.Viewer.

### Schritt 3: Rendern ausgeblendeter Spalten und Zeilen aktivieren
`SpreadsheetOptions` ermöglicht das Umschalten der Sichtbarkeit ausgeblendeter Zeilen und Spalten während der Konvertierung.  
`SpreadsheetOptions` ist der Einstellungscontainer, der festlegt, wie tabellenspezifische Funktionen – wie ausgeblendete Zellen, Gitternetzlinien und Arbeitsblatt‑Auswahl – verarbeitet werden.

### Schritt 4: Viewer mit Dokument initialisieren und rendern
Die Klasse `Viewer` ist die primäre Komponente zum Rendern von Dokumenten in GroupDocs.Viewer.  
Erstellen Sie eine `Viewer`‑Instanz, übergeben Sie den Pfad zur Excel‑Datei und rufen Sie die Methode `view` mit den vorbereiteten Optionen auf.  
Die Klasse `Viewer` ist der Einstiegspunkt von GroupDocs.Viewer; sie liest das Quelldokument und erzeugt das gewünschte Ausgabeformat.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Häufig gestellte Fragen

**Q: Beeinflusst das Aktivieren von `setRenderHiddenColumns(true)` die Leistung?**  
A: Das Rendern ausgeblendeter Spalten verursacht einen geringen Mehraufwand, aber die Auswirkung ist bei typischen Arbeitsmappen minimal. Bei sehr großen Blättern sollten Sie den Speicherverbrauch überwachen und ggf. die JVM‑Heap‑Größe erhöhen.

**Q: Kann ich eine XLSX‑Datei in eine einzelne HTML‑Seite statt mehrerer Seiten konvertieren?**  
A: Ja, setzen Sie einen benutzerdefinierten Dateinamen in `HtmlViewOptions` ohne den `{0}`‑Platzhalter, um eine einzelne HTML‑Datei zu erzeugen, die alle Arbeitsblätter enthält.

**Q: Wie kann ich ausgeblendete Tabellendaten nur für bestimmte Arbeitsblätter anzeigen?**  
A: Verwenden Sie `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)`, um bestimmte Blätter auszuwählen, bevor Sie das Rendern ausgeblendeter Elemente aktivieren.

**Q: Gibt es eine Möglichkeit, die Symbolleiste oder Navigation nach der Konvertierung zu verbergen?**  
A: Die von GroupDocs.Viewer erzeugte HTML‑Ausgabe ist statisch; Sie können Navigations‑Elemente manuell entfernen, indem Sie die erzeugte Vorlage bearbeiten oder benutzerdefiniertes CSS anwenden.

**Q: Welche Version von GroupDocs.Viewer ist für das Rendern ausgeblendeter Zeilen/Spalten erforderlich?**  
A: Die Funktion ist ab Version **22.0** verfügbar; wir empfehlen die neueste stabile Version (derzeit 25.2) für beste Leistung und Support.
