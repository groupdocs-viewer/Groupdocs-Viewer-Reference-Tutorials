## Apa itu “mengonversi Excel ke HTML”?

Mengonversi Excel ke HTML mengubah workbook `.xlsx` menjadi halaman HTML siap web sambil mempertahankan tata letak asli, gaya sel, rumus, dan data. HTML yang dihasilkan dapat ditampilkan di browser modern mana pun tanpa memerlukan Microsoft Office terpasang, menjadikannya ideal untuk portal web, dasbor pelaporan, dan platform kolaboratif.

## Mengapa menampilkan data spreadsheet tersembunyi?

Menampilkan baris dan kolom tersembunyi memastikan setiap informasi yang disimpan dalam workbook menjadi terlihat dalam output HTML, yang penting untuk audit, analisis data, dan skenario pendidikan. Dengan mengekspos sel tersembunyi, Anda menghindari kehilangan data secara tidak sengaja dan menjamin bahwa konsumen selanjutnya melihat dataset lengkap persis seperti yang ada di file sumber.

## Cara mengonversi Excel ke HTML dengan data tersembunyi

Untuk mengonversi workbook Excel ke HTML sambil memastikan baris dan kolom tersembunyi menjadi terlihat, Anda memuat file dengan GroupDocs.Viewer, mengonfigurasi `SpreadsheetOptions` untuk merender elemen tersembunyi, menyiapkan `HtmlViewOptions` untuk format output yang diinginkan, dan kemudian memanggil viewer untuk menghasilkan file HTML. Ikuti langkah-langkah di bawah ini untuk melakukannya.

### Langkah 1: Tentukan jalur direktori output
Tentukan folder tempat file HTML yang dihasilkan akan disimpan:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Langkah 2: Konfigurasikan opsi tampilan HTML
`HtmlViewOptions` mengontrol cara file HTML diproduksi, termasuk apakah sumber daya disematkan atau disimpan sebagai file terpisah.  
Kelas `HtmlViewOptions` adalah objek konfigurasi utama untuk rendering HTML di GroupDocs.Viewer.

### Langkah 3: Aktifkan rendering kolom dan baris tersembunyi
`SpreadsheetOptions` memungkinkan Anda mengubah visibilitas baris dan kolom tersembunyi selama konversi.  
`SpreadsheetOptions` adalah wadah pengaturan yang menentukan bagaimana fitur khusus spreadsheet—seperti sel tersembunyi, garis kisi, dan pemilihan lembar kerja—ditangani.

### Langkah 4: Inisialisasi Viewer dengan dokumen dan render
Kelas `Viewer` adalah komponen utama yang digunakan untuk merender dokumen di GroupDocs.Viewer.  
Buat instance `Viewer`, berikan jalur file Excel, dan panggil metode `view` dengan opsi yang telah disiapkan.  
Kelas `Viewer` adalah titik masuk GroupDocs.Viewer; ia membaca dokumen sumber dan menghasilkan format output yang diminta.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

**Q3: Bagaimana cara menangani dokumen besar dengan GroupDocs.Viewer?**

**Q4: Apakah memungkinkan menyesuaikan format output HTML?**

## Pertanyaan yang sering diajukan
**Q: Apakah mengaktifkan `setRenderHiddenColumns(true)` memengaruhi kinerja?**  
A: Merender kolom tersembunyi menambah overhead kecil, tetapi dampaknya minimal untuk workbook tipikal. Untuk lembar yang sangat besar, pantau penggunaan memori dan pertimbangkan meningkatkan ukuran heap JVM.

**Q: Bisakah saya mengonversi file XLSX menjadi satu halaman HTML alih‑alih beberapa halaman?**  
A: Ya, atur nama file khusus di `HtmlViewOptions` tanpa placeholder `{0}` untuk menghasilkan satu file HTML yang berisi semua lembar kerja.

**Q: Bagaimana cara menampilkan data spreadsheet tersembunyi hanya untuk lembar kerja tertentu?**  
A: Gunakan `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` untuk menargetkan lembar tertentu sebelum mengaktifkan rendering tersembunyi.

**Q: Apakah ada cara untuk menyembunyikan toolbar atau navigasi setelah konversi?**  
A: Output HTML yang dihasilkan oleh GroupDocs.Viewer bersifat statis; Anda dapat secara manual menghapus elemen navigasi dengan mengedit template yang dihasilkan atau menerapkan CSS khusus.

**Q: Versi GroupDocs.Viewer mana yang diperlukan untuk rendering baris/kolom tersembunyi?**  
A: Fitur ini tersedia mulai versi **22.0**; kami menyarankan menggunakan rilis stabil terbaru (saat ini 25.2) untuk kinerja dan dukungan terbaik.
