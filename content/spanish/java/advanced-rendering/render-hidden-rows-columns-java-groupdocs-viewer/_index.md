# Convertir Excel a HTML y renderizar filas y columnas ocultas en hojas de cálculo Java usando GroupDocs.Viewer

¿Estás teniendo problemas para **convertir Excel a HTML** y visualizar filas y columnas ocultas dentro de una hoja de cálculo al convertirla a HTML usando Java? ¡No estás solo! Muchos desarrolladores enfrentan este desafío al intentar mantener la integridad de la visualización de datos en diferentes formatos. Este tutorial te guiará sobre cómo renderizar eficazmente filas y columnas ocultas en hojas de cálculo usando GroupDocs.Viewer para Java, asegurando que no se pierda información crucial durante la conversión.

## Respuestas rápidas
- **¿Puede GroupDocs.Viewer convertir Excel a HTML?** Sí, proporciona soporte listo para usar para convertir archivos XLSX a HTML.
- **¿Serán visibles las filas y columnas ocultas en la salida HTML?** Cuando habilitas las opciones adecuadas, los datos ocultos se renderizan igual que las celdas visibles.
- **¿Qué artefacto Maven se requiere?** `com.groupdocs:groupdocs-viewer` (se recomienda la última versión).

## ¿Qué es “convertir Excel a HTML”?

Convertir Excel a HTML transforma un libro de trabajo `.xlsx` en páginas HTML listas para la web mientras preserva el diseño original, estilos de celda, fórmulas y datos. El HTML resultante puede mostrarse en cualquier navegador moderno sin necesidad de tener Microsoft Office instalado, lo que lo hace ideal para portales web, paneles de informes y plataformas colaborativas.

## ¿Por qué renderizar datos de hoja de cálculo ocultos?

Renderizar filas y columnas ocultas garantiza que cada pieza de información almacenada en el libro de trabajo sea visible en la salida HTML, lo cual es crucial para la auditoría, el análisis de datos y escenarios educativos. Al exponer celdas ocultas, evitas la pérdida accidental de datos y aseguras que los consumidores posteriores vean el conjunto de datos completo tal como existe en el archivo fuente.

## Cómo convertir Excel a HTML con datos ocultos

Para convertir un libro de Excel a HTML asegurando que filas y columnas ocultas se vuelvan visibles, cargas el archivo con GroupDocs.Viewer, configuras `SpreadsheetOptions` para renderizar elementos ocultos, estableces `HtmlViewOptions` para el formato de salida deseado y luego invocas al visor para generar los archivos HTML. Sigue los pasos a continuación para lograrlo.

### Paso 1: Definir la ruta del directorio de salida

Especifica la carpeta donde se guardarán los archivos HTML generados:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Paso 2: Configurar opciones de vista HTML

`HtmlViewOptions` controla cómo se producen los archivos HTML, incluyendo si los recursos se incrustan o se guardan como archivos separados.  
La clase `HtmlViewOptions` es el objeto de configuración central para la renderización HTML en GroupDocs.Viewer.

### Paso 3: Habilitar la renderización de columnas y filas ocultas

`SpreadsheetOptions` te permite alternar la visibilidad de filas y columnas ocultas durante la conversión.  
`SpreadsheetOptions` es el contenedor de ajustes que determina cómo se manejan características específicas de la hoja de cálculo, como celdas ocultas, líneas de cuadrícula y selección de hojas de trabajo.

### Paso 4: Inicializar Viewer con el documento y renderizar

La clase `Viewer` es el componente principal usado para renderizar documentos en GroupDocs.Viewer.  
Crea una instancia de `Viewer`, pasa la ruta del archivo Excel e invoca el método `view` con las opciones preparadas.  
La clase `Viewer` es el punto de entrada de GroupDocs.Viewer; lee el documento fuente y produce el formato de salida solicitado.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Preguntas frecuentes

**Q: ¿Afecta al rendimiento habilitar `setRenderHiddenColumns(true)`?**  
A: Renderizar columnas ocultas añade una pequeña sobrecarga, pero el impacto es mínimo para libros de trabajo típicos. Para hojas muy grandes, supervisa el uso de memoria y considera aumentar el heap de la JVM.

**Q: ¿Puedo convertir un archivo XLSX a una sola página HTML en lugar de varias páginas?**  
A: Sí, establece un nombre de archivo personalizado en `HtmlViewOptions` sin el marcador `{0}` para generar un único archivo HTML que contenga todas las hojas de cálculo.

**Q: ¿Cómo muestro datos de hoja de cálculo ocultos solo para hojas específicas?**  
A: Usa `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` para apuntar a hojas particulares antes de habilitar la renderización de datos ocultos.

**Q: ¿Hay forma de ocultar la barra de herramientas o la navegación después de la conversión?**  
A: La salida HTML generada por GroupDocs.Viewer es estática; puedes eliminar manualmente los elementos de navegación editando la plantilla generada o aplicando CSS personalizado.

**Q: ¿Qué versión de GroupDocs.Viewer se requiere para la renderización de filas/columnas ocultas?**  
A: La funcionalidad está disponible a partir de la versión **22.0**; recomendamos usar la última versión estable (actualmente 25.2) para obtener el mejor rendimiento y soporte.
