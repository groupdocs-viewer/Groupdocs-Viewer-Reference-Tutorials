## Che cos'è “convertire Excel in HTML”?
Convertire Excel in HTML trasforma una cartella di lavoro `.xlsx` in pagine HTML pronte per il web, preservando il layout originale, gli stili delle celle, le formule e i dati. L'HTML risultante può essere visualizzato in qualsiasi browser moderno senza la necessità di avere Microsoft Office installato, rendendolo ideale per portali web, dashboard di reporting e piattaforme collaborative.

## Perché renderizzare i dati nascosti del foglio di calcolo?

Esporre le celle nascoste evita perdite accidentali di dati e assicura che i consumatori finali vedano l'intero set di dati esattamente com'è nel file sorgente.

## Come convertire Excel in HTML con dati nascosti

Per convertire una cartella di lavoro Excel in HTML assicurandoti che righe e colonne nascoste diventino visibili, carichi il file con GroupDocs.Viewer, configuri `SpreadsheetOptions` per renderizzare gli elementi nascosti, imposti `HtmlViewOptions` per il formato di output desiderato e poi invochi il viewer per generare i file HTML. Segui i passaggi seguenti per realizzare questo.

### Passo 1: Definire il percorso della directory di output
Specifica la cartella dove verranno salvati i file HTML generati:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Passo 2: Configurare le opzioni di visualizzazione HTML
`HtmlViewOptions` controlla come vengono prodotti i file HTML, inclusa l'opzione di incorporare le risorse o salvarle come file separati.  
La classe `HtmlViewOptions` è l'oggetto di configurazione centrale per il rendering HTML in GroupDocs.Viewer.

### Passo 3: Abilitare il rendering di colonne e righe nascoste
`SpreadsheetOptions` ti consente di attivare o disattivare la visibilità di righe e colonne nascoste durante la conversione.  
`SpreadsheetOptions` è il contenitore delle impostazioni che determina come vengono gestite le funzionalità specifiche dei fogli di calcolo — come celle nascoste, linee della griglia e selezione dei fogli di lavoro.

### Passo 4: Inizializzare Viewer con documento e renderizzare
La classe `Viewer` è il componente principale usato per renderizzare i documenti in GroupDocs.Viewer.  
Crea un'istanza di `Viewer`, passa il percorso del file Excel e invoca il metodo `view` con le opzioni preparate.  
La classe `Viewer` è il punto di ingresso di GroupDocs.Viewer; legge il documento sorgente e produce il formato di output richiesto.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Domande frequenti

**Q: L'abilitazione di `setRenderHiddenColumns(true)` influisce sulle prestazioni?**  
A: Il rendering delle colonne nascoste aggiunge un piccolo overhead, ma l'impatto è minimo per le cartelle di lavoro tipiche. Per fogli molto grandi, monitora l'uso della memoria e considera di aumentare la dimensione dell'heap JVM.

**Q: Posso convertire un file XLSX in una singola pagina HTML invece di più pagine?**  
A: Sì, imposta un nome file personalizzato in `HtmlViewOptions` senza il segnaposto `{0}` per generare un unico file HTML che contenga tutti i fogli di lavoro.

**Q: Come visualizzo i dati nascosti del foglio di calcolo solo per fogli specifici?**  
A: Usa `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` per selezionare i fogli desiderati prima di abilitare il rendering dei dati nascosti.

**Q: Esiste un modo per nascondere la barra degli strumenti o la navigazione dopo la conversione?**  
A: L'output HTML generato da GroupDocs.Viewer è statico; puoi rimuovere manualmente gli elementi di navigazione modificando il modello generato o applicando CSS personalizzato.

**Q: Quale versione di GroupDocs.Viewer è necessaria per il rendering di righe/colonne nascoste?**  
A: La funzionalità è disponibile a partire dalla versione **22.0**; consigliamo di utilizzare l'ultima release stabile (attualmente 25.2) per le migliori prestazioni e supporto.
