# Convertir Excel en HTML et rendre les lignes et colonnes masquées dans les feuilles de calcul Java à l'aide de GroupDocs.Viewer

Êtes‑vous confronté à la difficulté de **convertir Excel en HTML** et de visualiser les lignes et colonnes masquées dans une feuille de calcul lors de la conversion en HTML avec Java ? Vous n’êtes pas seul ! De nombreux développeurs rencontrent ce problème lorsqu’ils essaient de préserver l’intégrité de la visualisation des données entre différents formats. Ce tutoriel vous guidera sur la façon de rendre efficacement les lignes et colonnes masquées dans les feuilles de calcul en utilisant GroupDocs.Viewer pour Java, garantissant qu’aucune information cruciale ne soit perdue lors de la conversion.

## Qu’est‑ce que « convertir Excel en HTML » ?

Convertir Excel en HTML transforme un classeur `.xlsx` en pages HTML prêtes pour le web tout en préservant la mise en page originale, les styles de cellules, les formules et les données. Le HTML résultant peut être affiché dans n’importe quel navigateur moderne sans nécessiter Microsoft Office, ce qui le rend idéal pour les portails web, les tableaux de bord de reporting et les plateformes collaboratives.

## Pourquoi rendre les données de feuille de calcul masquées ?

Rendre les lignes et colonnes masquées assure que chaque information stockée dans le classeur devienne visible dans la sortie HTML, ce qui est crucial pour l’auditabilité, l’analyse de données et les scénarios éducatifs. En exposant les cellules masquées, vous évitez les pertes de données accidentelles et garantissez que les utilisateurs finaux voient l’ensemble du jeu de données exactement tel qu’il existe dans le fichier source.

## Comment convertir Excel en HTML avec des données masquées

Pour convertir un classeur Excel en HTML tout en garantissant que les lignes et colonnes masquées deviennent visibles, vous chargez le fichier avec GroupDocs.Viewer, configurez le `SpreadsheetOptions` pour rendre les éléments masqués, définissez les `HtmlViewOptions` pour le format de sortie souhaité, puis invoquez le viewer pour générer les fichiers HTML. Suivez les étapes ci‑dessous pour y parvenir.

### Étape 1 : Définir le chemin du répertoire de sortie

Spécifiez le dossier où les fichiers HTML générés seront enregistrés :
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Étape 2 : Configurer les options d’affichage HTML

`HtmlViewOptions` contrôle la façon dont les fichiers HTML sont produits, y compris si les ressources sont incorporées ou enregistrées comme fichiers séparés.  
La classe `HtmlViewOptions` est l’objet de configuration central pour le rendu HTML dans GroupDocs.Viewer.

### Étape 3 : Activer le rendu des colonnes et lignes masquées

`SpreadsheetOptions` vous permet de basculer la visibilité des lignes et colonnes masquées pendant la conversion.  
`SpreadsheetOptions` est le conteneur de paramètres qui détermine comment les fonctionnalités spécifiques aux feuilles de calcul — telles que les cellules masquées, les lignes de grille et la sélection de feuilles de calcul — sont gérées.

### Étape 4 : Initialiser le Viewer avec le document et le rendre

La classe `Viewer` est le composant principal utilisé pour rendre les documents dans GroupDocs.Viewer.  
Créez une instance de `Viewer`, passez le chemin du fichier Excel, puis invoquez la méthode `view` avec les options préparées.  
La classe `Viewer` est le point d’entrée de GroupDocs.Viewer ; elle lit le document source et produit le format de sortie demandé.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Questions fréquemment posées

**Q : L’activation de `setRenderHiddenColumns(true)` affecte‑t‑elle les performances ?**  
**R :** Le rendu des colonnes masquées ajoute une petite surcharge, mais l’impact est minime pour les classeurs typiques. Pour des feuilles très grandes, surveillez l’utilisation de la mémoire et envisagez d’augmenter la taille du tas JVM.

**Q : Puis‑je convertir un fichier XLSX en une seule page HTML au lieu de plusieurs pages ?**  
**R :** Oui, définissez un nom de fichier personnalisé dans `HtmlViewOptions` sans le placeholder `{0}` pour générer un seul fichier HTML contenant toutes les feuilles de calcul.

**Q : Comment afficher les données masquées d’une feuille de calcul uniquement pour des feuilles spécifiques ?**  
**R :** Utilisez `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` pour cibler des feuilles particulières avant d’activer le rendu masqué.

**Q : Existe‑t‑il un moyen de masquer la barre d’outils ou la navigation après la conversion ?**  
**R :** La sortie HTML générée par GroupDocs.Viewer est statique ; vous pouvez supprimer manuellement les éléments de navigation en modifiant le modèle généré ou en appliquant du CSS personnalisé.

**Q : Quelle version de GroupDocs.Viewer est requise pour le rendu des lignes/colonnes masquées ?**  
**R :** La fonctionnalité est disponible à partir de la version **22.0** ; nous recommandons d’utiliser la dernière version stable (actuellement 25.2) pour les meilleures performances et le support.
