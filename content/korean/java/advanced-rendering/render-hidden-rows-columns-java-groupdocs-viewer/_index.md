# Excel을 HTML로 변환하고 Java 스프레드시트에서 숨겨진 행 및 열 렌더링하기 - GroupDocs.Viewer 사용

Are you struggling to **Excel을 HTML로 변환** and visualize hidden rows and columns within a spreadsheet when converting it to HTML using Java? You're not alone! Many developers face this challenge while trying to maintain the integrity of data visualization across different formats. This tutorial will guide you through how to effectively render hidden rows and columns in spreadsheets using GroupDocs.Viewer for Java, ensuring no crucial information is lost during conversion.

## 빠른 답변
- **GroupDocs.Viewer가 Excel을 HTML로 변환할 수 있나요?** Yes, it provides out‑of‑the‑box support for converting XLSX files to HTML.  
- **숨겨진 행과 열이 HTML 출력에 표시되나요?** 적절한 옵션을 활성화하면 숨겨진 데이터가 보이는 셀과 동일하게 렌더링됩니다.  
- **필요한 Maven 아티팩트는 무엇인가요?** `com.groupdocs:groupdocs-viewer` (latest version recommended).

## “Excel을 HTML로 변환”이란?

Excel을 HTML로 변환하면 `.xlsx` 워크북을 웹에 적합한 HTML 페이지로 변환하면서 원래 레이아웃, 셀 스타일, 수식 및 데이터를 보존합니다. 생성된 HTML은 Microsoft Office가 설치되지 않은 최신 브라우저에서도 표시될 수 있어 웹 포털, 보고 대시보드 및 협업 플랫폼에 이상적입니다.

## 왜 숨겨진 스프레드시트 데이터를 렌더링해야 할까요?

숨겨진 행과 열을 렌더링하면 워크북에 저장된 모든 정보가 HTML 출력에 표시되어 감사 가능성, 데이터 분석 및 교육 시나리오에 필수적입니다. 숨겨진 셀을 노출함으로써 실수로 인한 데이터 손실을 방지하고, 하위 사용자들이 원본 파일에 존재하는 전체 데이터 세트를 정확히 볼 수 있도록 보장합니다.

## 숨겨진 데이터를 포함하여 Excel을 HTML로 변환하는 방법

숨겨진 행과 열이 보이도록 Excel 워크북을 HTML로 변환하려면 GroupDocs.Viewer로 파일을 로드하고, `SpreadsheetOptions`를 구성하여 숨겨진 요소를 렌더링하도록 설정하고, 원하는 출력 형식을 위해 `HtmlViewOptions`를 설정한 뒤, 뷰어를 호출해 HTML 파일을 생성합니다. 아래 단계에 따라 수행하십시오.

### 단계 1: 출력 디렉터리 경로 정의
생성된 HTML 파일이 저장될 폴더를 지정합니다:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### 단계 2: HTML 보기 옵션 구성
`HtmlViewOptions`는 HTML 파일이 생성되는 방식을 제어하며, 리소스를 임베드할지 별도 파일로 저장할지를 포함합니다.  
`HtmlViewOptions` 클래스는 GroupDocs.Viewer에서 HTML 렌더링을 위한 핵심 구성 객체입니다.

### 단계 3: 숨겨진 열 및 행 렌더링 활성화
`SpreadsheetOptions`를 사용하면 변환 중 숨겨진 행과 열의 가시성을 전환할 수 있습니다.  
`SpreadsheetOptions`는 숨겨진 셀, 그리드 라인, 워크시트 선택 등 스프레드시트 전용 기능이 어떻게 처리되는지를 결정하는 설정 컨테이너입니다.

### 단계 4: 문서와 함께 Viewer 초기화 및 렌더링
`Viewer` 클래스는 GroupDocs.Viewer에서 문서를 렌더링하는 주요 구성 요소입니다.  
`Viewer` 인스턴스를 생성하고 Excel 파일 경로를 전달한 뒤, 준비된 옵션으로 `view` 메서드를 호출합니다.  
`Viewer` 클래스는 GroupDocs.Viewer의 진입점이며, 소스 문서를 읽어 요청된 출력 형식을 생성합니다.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## 자주 묻는 질문

**Q: `setRenderHiddenColumns(true)`를 활성화하면 성능에 영향을 줍니까?**  
A: 숨겨진 열을 렌더링하면 약간의 오버헤드가 추가되지만 일반 워크북에서는 영향이 미미합니다. 매우 큰 시트의 경우 메모리 사용량을 모니터링하고 JVM 힙 크기 확대를 고려하십시오.

**Q: XLSX 파일을 여러 페이지가 아닌 단일 HTML 페이지로 변환할 수 있나요?**  
A: 예, `{0}` 플레이스홀더 없이 `HtmlViewOptions`에 사용자 정의 파일 이름을 설정하면 모든 워크시트를 포함하는 단일 HTML 파일을 생성합니다.

**Q: 특정 워크시트에 대해서만 숨겨진 스프레드시트 데이터를 표시하려면 어떻게 해야 하나요?**  
A: 숨겨진 렌더링을 활성화하기 전에 `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)`를 사용해 특정 시트를 지정하십시오.

**Q: 변환 후 툴바나 네비게이션을 숨길 방법이 있나요?**  
A: GroupDocs.Viewer가 생성하는 HTML 출력은 정적이므로, 생성된 템플릿을 편집하거나 맞춤 CSS를 적용해 네비게이션 요소를 수동으로 제거할 수 있습니다.

**Q: 숨겨진 행/열 렌더링을 위해 필요한 GroupDocs.Viewer 버전은 무엇인가요?**  
A: 이 기능은 버전 **22.0**부터 제공되며, 최상의 성능과 지원을 위해 최신 안정 릴리스(현재 25.2)를 사용하는 것을 권장합니다.
