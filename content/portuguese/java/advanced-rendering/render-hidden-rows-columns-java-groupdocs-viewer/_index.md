# Converter Excel para HTML e renderizar linhas e colunas ocultas em planilhas Java usando GroupDocs.Viewer

Este tutorial vai guiá‑lo sobre como renderizar efetivamente linhas e colunas ocultas em planilhas usando GroupDocs.Viewer para Java, garantindo que nenhuma informação crucial seja perdida durante a conversão.

## O que é “converter Excel para HTML”?

Converter Excel para HTML transforma uma pasta de trabalho `.xlsx` em páginas HTML prontas para a web, preservando o layout original, estilos de célula, fórmulas e dados. O HTML resultante pode ser exibido em qualquer navegador moderno sem necessidade de Microsoft Office instalado, tornando‑o ideal para portais web, painéis de relatórios e plataformas colaborativas.

## Por que renderizar dados de planilha ocultos?

Renderizar linhas e colunas ocultas garante que cada informação armazenada na pasta de trabalho se torne visível na saída HTML, o que é crucial para auditoria, análise de dados e cenários educacionais. Ao expor células ocultas, você evita perda acidental de dados e assegura que os consumidores finais vejam o conjunto completo exatamente como está no arquivo fonte.

## Como converter Excel para HTML com dados ocultos

Para converter uma pasta de trabalho Excel para HTML garantindo que linhas e colunas ocultas se tornem visíveis, você carrega o arquivo com o GroupDocs.Viewer, configura o `SpreadsheetOptions` para renderizar elementos ocultos, define o `HtmlViewOptions` para o formato de saída desejado e, então, invoca o viewer para gerar os arquivos HTML. Siga os passos abaixo para realizar isso.

### Etapa 1: Definir o caminho do diretório de saída

Especifique a pasta onde os arquivos HTML gerados serão salvos:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Etapa 2: Configurar opções de visualização HTML

`HtmlViewOptions` controla como os arquivos HTML são produzidos, incluindo se os recursos são incorporados ou salvos como arquivos separados.  
A classe `HtmlViewOptions` é o objeto central de configuração para renderização HTML no GroupDocs.Viewer.

### Etapa 3: Habilitar a renderização de colunas e linhas ocultas

`SpreadsheetOptions` permite alternar a visibilidade de linhas e colunas ocultas durante a conversão.  
`SpreadsheetOptions` é o contêiner de configurações que determina como recursos específicos da planilha — como células ocultas, linhas de grade e seleção de planilhas — são tratados.

### Etapa 4: Inicializar o Viewer com o documento e renderizar

A classe `Viewer` é o componente principal usado para renderizar documentos no GroupDocs.Viewer.  
Crie uma instância de `Viewer`, passe o caminho do arquivo Excel e invoque o método `view` com as opções preparadas.  
A classe `Viewer` é o ponto de entrada do GroupDocs.Viewer; ela lê o documento fonte e produz o formato de saída solicitado.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Perguntas frequentes

**Q: Habilitar `setRenderHiddenColumns(true)` afeta o desempenho?**  
A: Renderizar colunas ocultas adiciona uma pequena sobrecarga, mas o impacto é mínimo para planilhas típicas. Para folhas muito grandes, monitore o uso de memória e considere aumentar o heap da JVM.

**Q: Posso converter um arquivo XLSX para uma única página HTML em vez de várias páginas?**  
A: Sim, defina um nome de arquivo personalizado em `HtmlViewOptions` sem o placeholder `{0}` para gerar um único arquivo HTML que contenha todas as planilhas.

**Q: Como exibir dados de planilha ocultos apenas para planilhas específicas?**  
A: Use `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` para direcionar planilhas específicas antes de habilitar a renderização de ocultos.

**Q: Existe uma maneira de ocultar a barra de ferramentas ou navegação após a conversão?**  
A: A saída HTML gerada pelo GroupDocs.Viewer é estática; você pode remover manualmente os elementos de navegação editando o template gerado ou aplicando CSS personalizado.

**Q: Qual versão do GroupDocs.Viewer é necessária para renderizar linhas/colunas ocultas?**  
A: O recurso está disponível a partir da versão **22.0**; recomendamos usar a versão estável mais recente (atualmente 25.2) para melhor desempenho e suporte.
