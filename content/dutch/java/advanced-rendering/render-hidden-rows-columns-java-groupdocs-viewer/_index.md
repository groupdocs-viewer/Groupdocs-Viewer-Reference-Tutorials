## Wat is “convert Excel to HTML”?
Het converteren van Excel naar HTML zet een `.xlsx`-werkmap om in web‑klare HTML‑pagina's, terwijl de oorspronkelijke lay-out, celstijlen, formules en gegevens behouden blijven. De resulterende HTML kan in elke moderne browser worden weergegeven zonder dat Microsoft Office geïnstalleerd hoeft te zijn, waardoor het ideaal is voor webportalen, rapportagedashboards en samenwerkingsplatformen.

## Waarom verborgen spreadsheet‑gegevens weergeven?

## Hoe Excel naar HTML converteren met verborgen gegevens

Om een Excel‑werkmap naar HTML te converteren terwijl verborgen rijen en kolommen zichtbaar worden, laad je het bestand met GroupDocs.Viewer, configureer je de `SpreadsheetOptions` om verborgen elementen weer te geven, stel je `HtmlViewOptions` in voor het gewenste outputformaat, en roep je vervolgens de viewer aan om de HTML‑bestanden te genereren. Volg de onderstaande stappen om dit te realiseren.

### Stap 1: Definieer pad van uitvoermap
Geef de map op waar de gegenereerde HTML‑bestanden worden opgeslagen:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Stap 2: HTML‑viewopties configureren
`HtmlViewOptions` bepaalt hoe HTML‑bestanden worden geproduceerd, inclusief of bronnen worden ingebed of als afzonderlijke bestanden worden opgeslagen.  
De `HtmlViewOptions`‑klasse is het centrale configuratie‑object voor HTML‑rendering in GroupDocs.Viewer.

### Stap 3: Rendering van verborgen kolommen en rijen inschakelen
`SpreadsheetOptions` stelt je in staat de zichtbaarheid van verborgen rijen en kolommen tijdens de conversie te schakelen.  
`SpreadsheetOptions` is de instellingencontainer die bepaalt hoe spreadsheet‑specifieke functies—zoals verborgen cellen, rasterlijnen en werkbladselectie—worden afgehandeld.

### Stap 4: Viewer initialiseren met document en renderen
De `Viewer`‑klasse is de primaire component die wordt gebruikt om documenten te renderen in GroupDocs.Viewer.  
Maak een `Viewer`‑instantie, geef het Excel‑bestandspad door, en roep de `view`‑methode aan met de voorbereide opties.  
De `Viewer`‑klasse is het toegangspunt van GroupDocs.Viewer; hij leest het bron‑document en produceert het gevraagde outputformaat.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Veelgestelde vragen

**Q: Heeft het inschakelen van `setRenderHiddenColumns(true)` invloed op de prestaties?**  
A: Het renderen van verborgen kolommen voegt een kleine overhead toe, maar de impact is minimaal voor typische werkboeken. Voor zeer grote bladen, houd het geheugenverbruik in de gaten en overweeg de JVM‑heap‑grootte te verhogen.

**Q: Kan ik een XLSX‑bestand naar één enkele HTML‑pagina converteren in plaats van meerdere pagina's?**  
A: Ja, stel een aangepaste bestandsnaam in `HtmlViewOptions` in zonder de `{0}`‑placeholder om één HTML‑bestand te genereren dat alle werkbladen bevat.

**Q: Hoe kan ik verborgen spreadsheet‑gegevens alleen voor specifieke werkbladen weergeven?**  
A: Gebruik `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` om specifieke bladen te targeten voordat je verborgen weergave inschakelt.

**Q: Is er een manier om de werkbalk of navigatie te verbergen na conversie?**  
A: De HTML‑output die door GroupDocs.Viewer wordt gegenereerd is statisch; je kunt navigatie‑elementen handmatig verwijderen door de gegenereerde template te bewerken of aangepaste CSS toe te passen.

**Q: Welke versie van GroupDocs.Viewer is vereist voor het renderen van verborgen rijen/kolommen?**  
A: De functie is beschikbaar vanaf versie **22.0**; we raden aan de nieuwste stabiele release te gebruiken (momenteel 25.2) voor de beste prestaties en ondersteuning.
