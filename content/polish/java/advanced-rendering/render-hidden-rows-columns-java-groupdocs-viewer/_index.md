## Jak konwertować Excel do HTML z ukrytymi danymi
Aby przekonwertować skoroszyt Excel do HTML, zapewniając jednocześnie widoczność ukrytych wierszy i kolumn, wczytujesz plik za pomocą GroupDocs.Viewer, konfigurujesz `SpreadsheetOptions`, aby renderować ukryte elementy, ustawiasz `HtmlViewOptions` dla żądanego formatu wyjściowego, a następnie wywołujesz viewer, aby wygenerować pliki HTML. Postępuj zgodnie z poniższymi krokami, aby to osiągnąć.

### Krok 1: Określ ścieżkę katalogu wyjściowego
Określ folder, w którym zostaną zapisane wygenerowane pliki HTML:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### Krok 2: Skonfiguruj opcje widoku HTML
`HtmlViewOptions` kontroluje sposób tworzenia plików HTML, w tym czy zasoby są osadzone czy zapisywane jako osobne pliki.  
Klasa `HtmlViewOptions` jest centralnym obiektem konfiguracyjnym dla renderowania HTML w GroupDocs.Viewer.

### Krok 3: Włącz renderowanie ukrytych kolumn i wierszy
`SpreadsheetOptions` pozwala przełączać widoczność ukrytych wierszy i kolumn podczas konwersji.  
`SpreadsheetOptions` jest kontenerem ustawień, który określa, jak obsługiwane są funkcje specyficzne dla arkuszy kalkulacyjnych — takie jak ukryte komórki, linie siatki i wybór arkuszy.

### Krok 4: Zainicjalizuj Viewer z dokumentem i renderuj
Klasa `Viewer` jest podstawowym komponentem używanym do renderowania dokumentów w GroupDocs.Viewer.  
Utwórz instancję `Viewer`, przekaż ścieżkę do pliku Excel i wywołaj metodę `view` z przygotowanymi opcjami.  
Klasa `Viewer` jest punktem wejścia GroupDocs.Viewer; odczytuje dokument źródłowy i generuje żądany format wyjściowy.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

## Najczęściej zadawane pytania

**Q: Czy włączenie `setRenderHiddenColumns(true)` wpływa na wydajność?**  
A: Renderowanie ukrytych kolumn dodaje niewielkie obciążenie, ale wpływ jest minimalny dla typowych skoroszytów. W przypadku bardzo dużych arkuszy monitoruj zużycie pamięci i rozważ zwiększenie rozmiaru sterty JVM.

**Q: Czy mogę przekonwertować plik XLSX na jedną stronę HTML zamiast wielu stron?**  
A: Tak, ustaw niestandardową nazwę pliku w `HtmlViewOptions` bez placeholdera `{0}`, aby wygenerować pojedynczy plik HTML zawierający wszystkie arkusze.

**Q: Jak wyświetlić ukryte dane arkusza tylko dla określonych arkuszy?**  
A: Użyj `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)`, aby wybrać konkretne arkusze przed włączeniem renderowania ukrytych elementów.

**Q: Czy istnieje sposób, aby ukryć pasek narzędzi lub nawigację po konwersji?**  
A: Wyjściowy HTML generowany przez GroupDocs.Viewer jest statyczny; możesz ręcznie usunąć elementy nawigacyjne, edytując wygenerowany szablon lub stosując niestandardowy CSS.

**Q: Jaka wersja GroupDocs.Viewer jest wymagana do renderowania ukrytych wierszy/kolumn?**  
A: Funkcja jest dostępna od wersji **22.0**; zalecamy użycie najnowszej stabilnej wersji (obecnie 25.2) dla najlepszej wydajności i wsparcia.
