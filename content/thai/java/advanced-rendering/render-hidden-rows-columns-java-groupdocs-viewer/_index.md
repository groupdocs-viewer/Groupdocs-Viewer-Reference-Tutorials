# แปลง Excel เป็น HTML และแสดงแถวและคอลัมน์ที่ซ่อนอยู่ในสเปรดชีต Java ด้วย GroupDocs.Viewer

## คำตอบอย่างรวดเร็ว
- **GroupDocs.Viewer สามารถแปลง Excel เป็น HTML ได้หรือไม่?** ใช่, มันให้การสนับสนุนแบบพร้อมใช้สำหรับการแปลงไฟล์ XLSX เป็น HTML.  
- **แถวและคอลัมน์ที่ซ่อนอยู่จะปรากฏในผลลัพธ์ HTML หรือไม่?** เมื่อคุณเปิดใช้งานตัวเลือกที่เหมาะสม ข้อมูลที่ซ่อนจะถูกแสดงเช่นเดียวกับเซลล์ที่มองเห็น.  
- **ต้องใช้ Maven artifact ใด?** `com.groupdocs:groupdocs-viewer` (แนะนำให้ใช้เวอร์ชันล่าสุด).  
- **ต้องการใบอนุญาตสำหรับการใช้งานในผลิตภัณฑ์หรือไม่?** ต้องมีใบอนุญาตถาวรสำหรับการใช้งานในผลิตภัณฑ์; มีใบอนุญาตทดลองใช้หรือใบอนุญาตชั่วคราวสำหรับการประเมินผล.  
- **วิธีนี้เข้ากันได้กับ Java 8 และใหม่กว่าไหม?** แน่นอน – ทำงานกับ JDK 8+.

## “convert Excel to HTML” คืออะไร?
การแปลง Excel เป็น HTML จะเปลี่ยนเวิร์กบุ๊ก `.xlsx` ให้เป็นหน้า HTML ที่พร้อมใช้งานบนเว็บโดยคงรูปแบบต้นฉบับ, สไตล์ของเซลล์, สูตร, และข้อมูลไว้ ผลลัพธ์ HTML สามารถแสดงในเบราว์เซอร์สมัยใหม่ใดก็ได้โดยไม่ต้องติดตั้ง Microsoft Office ทำให้เหมาะสำหรับพอร์ทัลเว็บ, แดชบอร์ดรายงาน, และแพลตฟอร์มการทำงานร่วมกัน.

## ทำไมต้องแสดงข้อมูลสเปรดชีตที่ซ่อนอยู่?
การแสดงแถวและคอลัมน์ที่ซ่อนอยู่ทำให้ข้อมูลทุกส่วนที่เก็บไว้ในเวิร์กบุ๊กปรากฏในผลลัพธ์ HTML ซึ่งสำคัญต่อการตรวจสอบ, การวิเคราะห์ข้อมูล, และสถานการณ์การศึกษา โดยการเปิดเผยเซลล์ที่ซ่อน คุณจะหลีกเลี่ยงการสูญเสียข้อมูลโดยไม่ได้ตั้งใจและรับประกันว่าผู้ใช้ต่อไปจะเห็นชุดข้อมูลเต็มรูปแบบตามที่อยู่ในไฟล์ต้นฉบับ.

## วิธีแปลง Excel เป็น HTML พร้อมข้อมูลที่ซ่อนอยู่

เพื่อแปลงเวิร์กบุ๊ก Excel เป็น HTML พร้อมให้แถวและคอลัมน์ที่ซ่อนอยู่ปรากฏ คุณต้องโหลดไฟล์ด้วย GroupDocs.Viewer, กำหนดค่า `SpreadsheetOptions` เพื่อแสดงองค์ประกอบที่ซ่อน, ตั้งค่า `HtmlViewOptions` สำหรับรูปแบบผลลัพธ์ที่ต้องการ, แล้วเรียกใช้ viewer เพื่อสร้างไฟล์ HTML ทำตามขั้นตอนด้านล่างเพื่อทำให้สำเร็จ.

### ขั้นตอนที่ 1: กำหนดเส้นทางไดเรกทอรีผลลัพธ์
ระบุโฟลเดอร์ที่ไฟล์ HTML ที่สร้างขึ้นจะถูกบันทึก:
```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path outputDirectory = Paths.get("YOUR_OUTPUT_DIRECTORY", "RenderHiddenRowsAndColumns");
```

### ขั้นตอนที่ 2: กำหนดค่า HTML view options
`HtmlViewOptions` ควบคุมวิธีการสร้างไฟล์ HTML รวมถึงว่าจะฝังทรัพยากรหรือบันทึกเป็นไฟล์แยก  
คลาส `HtmlViewOptions` เป็นอ็อบเจกต์การกำหนดค่ากลางสำหรับการแสดงผล HTML ใน GroupDocs.Viewer.

### ขั้นตอนที่ 3: เปิดการแสดงแถวและคอลัมน์ที่ซ่อนอยู่
`SpreadsheetOptions` ให้คุณสลับการมองเห็นของแถวและคอลัมน์ที่ซ่อนอยู่ระหว่างการแปลง  
`SpreadsheetOptions` เป็นคอนเทนเนอร์การตั้งค่าที่กำหนดวิธีจัดการคุณลักษณะเฉพาะของสเปรดชีต เช่น เซลล์ที่ซ่อน, เส้นกริด, และการเลือกแผ่นงาน.

### ขั้นตอนที่ 4: เริ่มต้น Viewer ด้วยเอกสารและทำการแสดงผล
คลาส `Viewer` เป็นส่วนประกอบหลักที่ใช้ในการแสดงผลเอกสารใน GroupDocs.Viewer  
สร้างอินสแตนซ์ของ `Viewer`, ส่งเส้นทางไฟล์ Excel, และเรียกเมธอด `view` พร้อมตัวเลือกที่เตรียมไว้  
คลาส `Viewer` เป็นจุดเริ่มต้นของ GroupDocs.Viewer; มันอ่านเอกสารต้นทางและสร้างรูปแบบผลลัพธ์ที่ร้องขอ.
```java
import com.groupdocs.viewer.options.HtmlViewOptions;

// Create a file path format for rendering each page.
Path pageFilePathFormat = outputDirectory.resolve("page_{0}.html");

HtmlViewOptions viewOptions = HtmlViewOptions.forEmbeddedResources(pageFilePathFormat);
```

**Q3: ฉันจะจัดการกับเอกสารขนาดใหญ่ด้วย GroupDocs.Viewer อย่างไร?**  
A3: ปรับการจัดการหน่วยความจำโดยการตั้งค่า heap ของ Java และหากจำเป็น ให้แบ่งเวิร์กบุ๊กขนาดใหญ่เป็นส่วนย่อยก่อนทำการแสดงผล.

**Q4: สามารถปรับแต่งรูปแบบผลลัพธ์ HTML ได้หรือไม่?**  
A4: ใช่, คุณสามารถกำหนดตัวเลือกต่าง ๆ ด้วย `HtmlViewOptions` เพื่อปรับรูปลักษณ์, ฝังทรัพยากร, หรือสร้างไฟล์ HTML หน้าเดียว.

**Q5: วิธีที่ดีที่สุดในการแก้ไขปัญหากับ GroupDocs.Viewer คืออะไร?**  
A5: ปรึกษาเอกสารอย่างเป็นทางการและฟอรั่มชุมชน, ตรวจสอบว่าการพึ่งพา Maven ทั้งหมดตรงกับเวอร์ชันของไลบรารี, และเปิดการบันทึกแบบละเอียดเพื่อเก็บข้อมูลข้อผิดพลาดอย่างละเอียด.

## คำถามที่พบบ่อย

**Q: การเปิดใช้งาน `setRenderHiddenColumns(true)` มีผลต่อประสิทธิภาพหรือไม่?**  
A: การแสดงคอลัมน์ที่ซ่อนเพิ่มภาระเล็กน้อย, แต่ผลกระทบน้อยสำหรับเวิร์กบุ๊กทั่วไป. สำหรับชีตขนาดใหญ่มาก, ควรตรวจสอบการใช้หน่วยความจำและพิจารณาเพิ่มขนาด heap ของ JVM.

**Q: ฉันสามารถแปลงไฟล์ XLSX เป็นหน้า HTML หน้าเดียวแทนหลายหน้าได้หรือไม่?**  
A: ใช่, ตั้งชื่อไฟล์แบบกำหนดเองใน `HtmlViewOptions` โดยไม่มีตัวแปร `{0}` เพื่อสร้างไฟล์ HTML หน้าเดียวที่รวมทุกแผ่นงาน.

**Q: ฉันจะแสดงข้อมูลสเปรดชีตที่ซ่อนเฉพาะสำหรับแผ่นงานที่กำหนดเท่านั้นอย่างไร?**  
A: ใช้ `viewOptions.getSpreadsheetOptions().setWorksheetIndexes(...)` เพื่อกำหนดแผ่นงานที่ต้องการก่อนเปิดการแสดงผลข้อมูลที่ซ่อน.

**Q: มีวิธีใดที่จะซ่อนแถบเครื่องมือหรือการนำทางหลังการแปลงหรือไม่?**  
A: ผลลัพธ์ HTML ที่สร้างโดย GroupDocs.Viewer เป็นแบบคงที่; คุณสามารถลบองค์ประกอบการนำทางด้วยตนเองโดยแก้ไขเทมเพลตที่สร้างหรือใช้ CSS แบบกำหนดเอง.

**Q: ต้องใช้เวอร์ชันใดของ GroupDocs.Viewer เพื่อการแสดงแถว/คอลัมน์ที่ซ่อน?**  
A: ฟีเจอร์นี้มีตั้งแต่เวอร์ชัน **22.0**; เราแนะนำให้ใช้เวอร์ชันที่เสถียรล่าสุด (ปัจจุบัน 25.2) เพื่อประสิทธิภาพและการสนับสนุนที่ดีที่สุด.
